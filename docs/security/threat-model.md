# LabPass threat model (STRIDE) — S13

**Scope:** API (NestJS/Fastify), admin console (Next.js), kiosk (Electron + PC/SC reader), student app (PWA + Android
HCE app), worker, PostgreSQL, Redis, notification providers. **Assets:** stock ledger (I2), student identities and
contacts, device/kiosk tokens, DESFire keys, credentials (device keys, passkeys), admin accounts.
**Trust boundaries:** phone ↔ reader (NFC), phone ↔ API (internet/campus Wi-Fi), kiosk renderer ↔ kiosk main (IPC),
kiosk main ↔ API (LAN/TLS), admin browser ↔ API, API ↔ SIS / SMTP / SMS / WhatsApp.

Every threat lists its mitigation and the **test that attacks it**. "T-…" ids are referenced from the tests.
