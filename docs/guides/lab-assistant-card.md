# LabPass — Lab assistant card / Fiche assistant de laboratoire

_Print on one A4 sheet and keep it next to the kiosk. · À imprimer sur une feuille A4, à garder près de la borne._

## Students / Étudiants

| The student has… / L’étudiant a…                            | At the kiosk / À la borne                                                                                                                                                                                                              |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ICTU card / Carte ICTU                                      | Tap the card on the reader. / Poser la carte sur le lecteur.                                                                                                                                                                           |
| Android phone with LabPass / Téléphone Android avec LabPass | **Unlock** the phone, then tap it on the reader. / **Déverrouiller** le téléphone, puis le poser sur le lecteur.                                                                                                                       |
| iPhone or no NFC / iPhone ou sans NFC                       | Open the LabPass app → _Show my LabPass code_ → scan the code shown on the kiosk. / Ouvrir l’app LabPass → _Montrer mon code LabPass_ → scanner le code de la borne.                                                                   |
| Nothing / Rien                                              | _Use my matricule_ → type the matricule → enter the LabPass PIN, **or** you confirm with **your assistant PIN**. / _Utiliser mon matricule_ → saisir le matricule → PIN LabPass, **ou** vous confirmez avec **votre PIN d’assistant**. |

Then: choose the items in the list → _Borrow_ / _Return_ → wait for the green tick. / Ensuite : choisir les articles → _Emprunter_ / _Rendre_ → attendre la coche verte.

**Before confirming a matricule entry, check the student’s ID card.** / **Avant de confirmer une saisie de matricule, vérifiez la carte d’étudiant.**

## Kiosk messages / Messages de la borne

| Message                                                     | Do / À faire                                                                                                                                                  |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Card reader not connected / Lecteur de cartes non connecté  | Replug the reader’s USB cable, wait 5 s. / Rebrancher le câble USB du lecteur, attendre 5 s. Still red → overlay → _Restart card reader_.                     |
| LabPass server unreachable / Serveur LabPass injoignable    | Lending continues offline; nothing to do. Tell the lab admin if it lasts. / Les prêts continuent hors ligne. Prévenir le responsable si cela dure.            |
| Unknown card / Carte inconnue                               | The student uses _Link this card_ with their matricule; the admin approves it. / L’étudiant utilise _Lier cette carte_ avec son matricule ; l’admin approuve. |
| Phone taps but nothing happens / Le téléphone ne réagit pas | Unlock the phone; hold it flat on the reader for 2 s. / Déverrouiller le téléphone ; le tenir à plat 2 s sur le lecteur.                                      |
| Overdue items block borrowing / Retard bloquant             | The student must return the overdue items first. / L’étudiant doit d’abord rendre le matériel en retard.                                                      |

## Assistant overlay / Menu assistant

Press and hold the **LabPass logo** (top left) for **2 seconds**, then type the **service PIN**. / Maintenir le **logo LabPass** (en haut à gauche) **2 secondes**, puis saisir le **PIN de service**.

- _Restart card reader_ / _Redémarrer le lecteur_
- _Reload screen_ / _Recharger l’écran_
- _Allow offline loans for 2 more hours_ / _Autoriser les prêts hors ligne 2 heures de plus_
- _Unregister this kiosk_, _Exit kiosk mode_: lab admin only / _Désenregistrer_, _Quitter le mode kiosque_ : responsable uniquement

Never leave the overlay open. Never write PINs on this sheet. / Ne laissez jamais le menu ouvert. N’écrivez jamais de PIN sur cette fiche.
